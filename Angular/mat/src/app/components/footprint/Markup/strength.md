
# ТЗ: Плагин “Strength Box” (анализ силы рынка внутри выделенного прямоугольника)

## 1) Идея и назначение

Плагин создаёт **прямоугольник-аннотацию** на графике (по времени и цене).
Внутри прямоугольника рисуется:

1. **Итог силы рынка** (“Strong Bull / Neutral / Strong Bear”)
2. **Стрелка результата** (куда реально “вытолкали цену”)
3. **Карта давления (Effort vs Result)** — где рынок поглощали (absorption)
4. **Мини-индикаторы причин** (дельта, эффективность, поглощение, дисбалансы)

Цель: одним взглядом понять:

* **давили ли продавцы/покупатели**
* **двигалась ли цена от этого**
* **где стояла стена (поглощение)**

---

## 2) UX поведение

### 2.1 Создание бокса

* Пользователь активирует инструмент **Strength Box**
* Зажимает ЛКМ и выделяет прямоугольник (время+цена)
* После отпускания создаётся объект “StrengthBox”
* Если включен `dockable` (по умолчанию), то после отпускания ЛКМ прямоугольник докается как в Profile (dockable-поля объемов Ask/Bid):
  * X: округление до целых колонок (баров); если `x1 == x2` → расширить до 1 бара
  * Y: округление к сетке `priceScale` и сдвиг на `-priceScale/2`, чтобы границы совпали с ценовыми ячейками; если `y1 == y2` → расширить на 1 тик

### 2.2 После создания

* Бокс остаётся на графике как объект
* Можно:

  * перетаскивать
  * менять размер за маркеры по углам
  * удалить
  * (опционально) двойной клик → “Режим заметки” (см. 7)

---

## 3) Что рисуем ВНУТРИ прямоугольника (макет)

### 3.1 Верхняя строка (заголовок)

Внутри прямоугольника, сверху, рисуем “шапку”:

**(A) Вердикт + Score**

```
+72  STRONG BULL
```

или

```
-48  BEAR / WEAK
```

* `Score` диапазон: `[-100..+100]`
* Вердикт:

  * `+60..+100`: STRONG BULL
  * `+20..+59`: BULL / BUY PRESSURE
  * `-19..+19`: NEUTRAL / BALANCE
  * `-20..-59`: BEAR / SELL PRESSURE
  * `-60..-100`: STRONG BEAR

**(B) Короткая причина (1 строка)**
Пример:

* `Sell absorbed → price holds`
* `Buy trapped at highs`
* `Effort high, result weak → absorption`
* `Clean drive up`

> Эта строка выбирается по доминирующему паттерну (см. 6.4)

---

### 3.2 Главный рисунок: “Стрелка результата”

В центре прямоугольника рисуется **большая стрелка**:

* направление: от левого края к правому (время идёт вправо)
* вертикальный наклон:

  * вверх, если `priceEnd > priceStart`
  * вниз, если `priceEnd < priceStart`
  * почти горизонтально, если изменения минимальные

**Толщина стрелки** = сила движения (нормализованная)

* толще = “рынок реально протащил цену”
* тонкая/пунктир = “толкали, но не вышло”

---

### 3.3 Карта давления по цене (HeatBand внутри бокса)

Это ключевой элемент, чтобы **видно было поглощение прямо в выделении**.

Внутри прямоугольника рисуется **горизонтальная “тепловая полоса” по цене** (по высоте прямоугольника), например 20–40 “ценовых бакетов”:

Для каждого бакета (уровень цены внутри выделения) считаем:

* `AskSumLevel` и `BidSumLevel` (сумма по кластерам в выделении)
* `DeltaLevel = AskSumLevel - BidSumLevel`
* `AbsorbHintLevel` (см. ниже)

**Отрисовка:**

* если `DeltaLevel` сильно > 0 → “покупки доминируют” (верхняя/позитивная заливка)
* если `DeltaLevel` сильно < 0 → “продажи доминируют”
* если при этом цена **не проходила уровень** или быстро возвращалась → уровень помечается как **Absorption Zone**

✅ Визуально это даёт эффект:

* где шли основные сделки
* где их “переварили”
* на каких ценах стояли лимитники

---

### 3.4 Зоны поглощения (Absorption Zones)

Если внутри выделения найдены уровни с сильным поглощением:

* рисуем **горизонтальные полупрозрачные “плашки”** (как зоны) по цене
* толщина зоны = 1–3 тика (или 1 бакет)
* подпись прямо внутри зоны:

  * `ABSORB BUY` (поглощение покупок сверху)
  * `ABSORB SELL` (поглощение продаж снизу)

Пример:

* внизу прямоугольника зона “ABSORB SELL” → продавили по сделкам, но ниже не пустили → сила покупателей

---

### 3.5 Нижняя строка: мини-панель метрик (без тултипов)

Внизу прямоугольника рисуется компактная строка (в одну линию):

Пример:

```
Δ: +18.4k   Eff: 0.62   Abs: Bulls 5 / Bears 1   ImbStacks: 3
```

Где:

* `Δ` = суммарная дельта в выделении
* `Eff` = эффективность (результат/усилие)
* `Abs` = сколько баров с поглощением в пользу быков/медведей
* `ImbStacks` = число stacked imbalance (если доступно)

---

## 4) Входные данные

### 4.1 Выделение

* прямоугольник: `t0..t1`, `pMin..pMax`
* бары внутри времени `bars[]`

### 4.2 Свечи

Для каждого бара:

* OHLC
* delta (ask-bid) по бару (если есть)

### 4.3 Кластера

Для каждого бара:

* уровни цены с `askVolumeLevel`, `bidVolumeLevel`

---

## 5) Расчёты (что считать)

### 5.1 Итоговое движение цены (Result)

* `priceStart` = Open первой свечи в выделении
* `priceEnd` = Close последней свечи в выделении
* `priceChange = priceEnd - priceStart`

### 5.2 Усилие (Effort)

* `deltaTotal = Σ deltaBar`
* `absDeltaTotal = Σ |deltaBar|`
* если delta нет → использовать объём (`volumeTotal`)

### 5.3 Эффективность движения (Effort vs Result)

`efficiency = |priceChange| / max(absDeltaTotal, eps)`

Смысл:

* много дельты, а цена почти не ушла → поглощение/борьба

### 5.4 Асимметрия реакции (главная “сила/слабость”)

Для баров внутри выделения:

* `moveBar = close - open`

* `buyPressure = Σ deltaBar where deltaBar>0`

* `sellPressure = Σ |deltaBar| where deltaBar<0`

* `buyMove = Σ max(moveBar,0) on deltaBar>0`

* `sellMove = Σ max(-moveBar,0) on deltaBar<0`

`buyResponse = buyMove / max(buyPressure, eps)`
`sellResponse = sellMove / max(sellPressure, eps)`

`responseAsym = (buyResponse - sellResponse) / max(buyResponse + sellResponse, eps)` → `[-1..+1]`

---

## 6) Поглощение и дисбалансы

### 6.1 Поглощение на барах (Absorption Bars)

Для каждого бара считаем:
`closePos = (close - low) / max(high-low, eps)`

Порог по дельте: адаптивный `minAbsDelta = percentile(|deltaBar|, 60%)`

**Bull Absorption Bar** если:

* `deltaBar < -minAbsDelta`
* `closePos >= 0.7`

**Bear Absorption Bar** если:

* `deltaBar > +minAbsDelta`
* `closePos <= 0.3`

Счётчики:

* `bullAbsCount`
* `bearAbsCount`

---

### 6.2 Поглощение по уровням (Absorption Zones)

Для каждого уровня цены (по кластерам) в выделении:

Считаем суммарные:

* `AskSumLevel`, `BidSumLevel`
* `DeltaLevel = AskSumLevel - BidSumLevel`

Признак зоны поглощения делаем так (простая и рабочая логика):

* уровень считается “hot”, если `totalVolumeLevel` попал в топ X% по объёму в выделении (например top 10%)
* далее классификация:

  * если `DeltaLevel сильно положительная`, **а рынок не смог подняться выше уровня** → `ABSORB BUY` (покупателей удержали)
  * если `DeltaLevel сильно отрицательная`, **а рынок не смог продавить ниже** → `ABSORB SELL`

Упрощённое правило “не смог пройти”:

* взять `maxPriceAfterLevel` и `minPriceAfterLevel` в пределах выделения
* если уровень был верхом и цена не закрепилась выше N тиков → absorption сверху
* аналогично снизу

---

### 6.3 Imbalance / Stacked Imbalance

На уровне:
`imb = ask / max(bid,1)`
порог `imbThreshold = 3.0`

BuyImb: `imb >= 3`
SellImb: `imb <= 1/3`

Stacked: последовательность `N=3` уровней подряд

---

### 6.4 Выбор “короткой причины” (строка под заголовком)

Если `responseAsym` сильно положительная:

* `"Buys drive, sells absorbed"`

Если сильно отрицательная:

* `"Sells drive, buys trapped"`

Если `efficiency` низкая и `absDeltaTotal` высокая:

* `"Effort high, result weak → absorption"`

Если efficiency высокая:

* `"Clean drive"`

---

## 7) Режим заметки (текст внутри прямоугольника)

Это важно: “внутри можно что-то написать”.

### 7.1 Ручной текст

* Двойной клик по боксу → появляется editable-text area
* Пользователь может написать 1–3 строки:

  * “набрал лонг”
  * “перелом”
  * “поглотили продавца”

### 7.2 Автотекст по умолчанию (если пользователь не редактирует)

Плагин сразу вставляет короткую авто-заметку:

Пример:

```
Strong Bull: sells absorbed at lows
```

---

## 8) Итоговый StrengthScore

Компоненты:

* `S1 = responseAsym` ([-1..1])
* `S2 = sign(priceChange) * normalizedEfficiency` ([-1..1])
* `S3 = (bullAbsCount - bearAbsCount)/barsCount` ([-1..1])
* `S4 = (buyStackCount - sellStackCount) normalized` ([-1..1], опционально)

Итог:
`strength = 0.45*S1 + 0.25*S2 + 0.20*S3 + 0.10*S4`
`Score = round(strength*100)`

Если кластеров нет → `S4=0`
Если дельты нет → `S1=0`, `S3` по объёму/closePos упрощённо

---

## 9) Что должно быть видно “с первого взгляда”

Внутри прямоугольника ОБЯЗАТЕЛЬНО:

✅ **Большой вывод (Score + Bull/Bear)**
✅ **Стрелка “куда реально пришли”**
✅ **Зоны поглощения по цене** (хотя бы 1–3 ключевые)
✅ **Строка метрик снизу**

---

## 10) Acceptance Criteria (готовность)

1. Выделение → появляется StrengthBox внутри которого уже есть текст/графика
2. По явно сильному участку вверх Score стабильно > +50
3. По “давят продажами, но не падаем” появляется зона `ABSORB SELL`
4. Пользователь может руками написать заметку внутри и она сохраняется
5. Всё выглядит читабельно при масштабировании (минимальные размеры шрифтов/скейл)
6. При включенном `dockable` границы бокса докаются к бару и шагу цены так же, как в Profile (Ask/Bid)
