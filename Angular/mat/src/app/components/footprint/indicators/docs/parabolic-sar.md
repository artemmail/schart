# Parabolic SAR

Purpose: Dotted stop-and-reverse indicator above/below price.

Parameters:
- Step, Max Step.
- Dot Size.
- Color.
- Highlight Reversals.

Calculation:
- Standard PSAR using extreme point (EP) and acceleration factor (AF).
- Reversal flips trend when price crosses SAR.

Notes:
- Rendered as points (not a continuous line).
- Reversal markers use diamond points with the same color.
