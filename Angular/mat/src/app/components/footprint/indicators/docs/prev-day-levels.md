# Previous Day Levels

Purpose: Shows previous day High/Low/Close and today's Open.

Parameters:
- Show Prev High / Low / Close / Today Open.
- Extend: Only Today / Full Right.
- Colors for each line, Width, Line Style.

Calculation:
- For each day, levels are computed from the previous day's H/L/C.
- Today Open uses the first bar open of the day.

Notes:
- "Only Today" shows levels only for the latest day in view.
