# Лидеры объемов, роста, падения

## Где находится
`Инструменты для трейдеров` -> `Лидеры объемов, роста, падения, BID, ASK`.

## Что делает
Таблица лидеров с фильтрами по рынку/диапазону/выборке.
Есть быстрые ссылки в фундаментал, отчетность, дивиденды, акционеров и FootPrint.

## Как устроен экран
Это один из ключевых «сканеров идей» в StockChart.ru. Сверху задаются параметры отбора:
- рынок (селектор),
- размер выборки (`Top`),
- период через пресет (неделя/месяц/год и т.п.),
- произвольный диапазон дат (DateRange).

После нажатия `Показать` формируется таблица. Для рынка акций (MOEX) обычно доступны дополнительные колонки‑иконки:
- `Финансовые показатели`,
- `МСФУ/РНБО` (отчетность),
- `Дивиденды`,
- `Собственники`.

Название бумаги кликабельно и открывает `FootPrint` с тикером (часто в дневном режиме), чтобы быстро перейти от «табличного сигнала» к чтению объема.

## Как использовать на практике
1. Начните с рынка и диапазона (например последняя неделя или месяц).
2. Смотрите лидеров по объему и изменению.
3. Выберите 3–10 тикеров и откройте их в `FootPrint`:
   - есть ли агрессия,
   - есть ли поглощение,
   - где крупные принты и дисбалансы.
4. Если тикер «интересный фундаментально», проверьте отчетность/дивиденды по быстрым ссылкам.

## Практические user-cases
- **Утренний отбор**: сформировать список активных бумаг «на сегодня».
- **Скрин по волатильности**: найти сильные движения, затем оценить структуру объема.
- **Список тикеров для портфеля**: быстро собрать кандидатов и перенести их в расчет Марковица.
