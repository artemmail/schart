# Админка: Тарифы

## Где находится
`Админка` -> `Тарифы`.

## Что делает
Управление тарифными планами:
- скидочная дата,
- обычные/реферальные планы,
- создание, изменение, удаление.

## Скидочный период
Вверху задается дата, до которой действует скидка. Это удобно для акций и временных предложений.

## Тарифные планы
Форма тарифа содержит ключевые поля:
- интервал и количество (например «месяц 1», «год 1» и т.п.),
- обычная цена и цена со скидкой,
- код услуги,
- опции реферального тарифа (интервал/количество для реферала).

Ниже показывается список тарифов с действиями `Редактировать` и `Удалить`.

## Практические админские сценарии
- Запустить скидку на период и заранее задать дату окончания.
- Добавить новый план (например на 3/6/12 месяцев).
- Скорректировать реферальные условия без ручных правок в базе.
