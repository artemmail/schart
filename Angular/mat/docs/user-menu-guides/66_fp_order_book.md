# FootPrint: Биржевой стакан

## Где находится
FootPrint -> `Доп. инструменты` -> `Биржевой стакан`.

## Что делает
Показывает live-лестницу bid/ask с графической глубиной рынка.

## Важно
Для исторических диапазонов без live-данных стакан может быть пуст.

## Как читать стакан в связке с FootPrint
Стакан полезен не сам по себе, а в комбинации:
- FootPrint показывает, **что уже проторговали**,
- стакан показывает, **что стоит сейчас** (где ликвидность может удержать/пустить цену).

На экране есть:
- две стороны (покупка/продажа),
- визуальные бары, которые дают быстрый взгляд на относительную глубину.

## Практические user-cases
- Оценить спред и «насколько легко» цене пройти уровень.
- Посмотреть, есть ли крупная ликвидность перед важной зоной, найденной через `Volume Search`.
- Быстро понять, рынок сейчас «тонкий» или «плотный».
