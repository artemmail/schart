# FootPrint: Крупнейшие сделки

## Где находится
FootPrint -> `Доп. инструменты` -> `Крупнейшие сделки`.

## Что делает
Показывает топ-сделки за выбранный период по текущему тикеру с сортировкой и пагинацией.

## Что полезно смотреть
В таблице обычно есть:
- количество (объем),
- тип (покупка/продажа),
- дата и время сделки,
- цена.

Это удобный «быстрый слой» поверх кластера: иногда достаточно увидеть 2–3 крупные сделки, чтобы понять, почему свеча выглядит так, как выглядит.

## Практические user-cases
- Подтвердить импульс: «рост сделан крупными покупками» или «рост на пустоте».
- Найти момент входа/выхода: крупная сделка часто совпадает с локальным экстремумом.
- Разобрать день постфактум: открыть диапазон и посмотреть топ сделок без прокрутки всего кластера.
