# Доска опционов

## Где находится
`Инструменты для трейдеров` -> `Доска опционов`.

## Что делает
Показывает таблицы CALL/PUT по серии:
- бид/оффер/last,
- IV и Greeks,
- сортировка/фильтры,
- автообновление.

## Как использовать
Клик по строке открывает карточку конкретного опциона.

## Что здесь удобно для трейдера
Это экран «для глаз и рук»:
- сверху выбираете базовый актив, тип, серию и количество строк вокруг центрального страйка,
- ниже получаете две таблицы `CALL` и `PUT`, где можно быстро найти ликвидные страйки и оценить IV/греки.

Есть дополнительные переключатели:
- `Only tradable` (показывать только реально торгуемые),
- `Only with trades` (только со сделками),
- `Only near ATM` (сжать таблицу вокруг центральной зоны),
- сортировка по `Strike / IV / Trades` и направление `Asc/Desc`,
- `Auto-refresh` (обновление каждые ~15 секунд).

## Практические user-cases
- **Поиск ликвидности**: включить `Only tradable` и быстро увидеть, где есть бид/оффер и сделки.
- **Подбор ног стратегии**: открыть `CALL` и `PUT` одновременно и выбрать страйки для спреда/стрэддла.
- **Переход в детали**: клик по строке -> карточка опциона (удобно, когда надо быстро проверить конкретный SECID).
