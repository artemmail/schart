# Дневной объем торгов Московской Биржи

## Где находится
`Инструменты для трейдеров` -> `Дневной объем торгов Московской Биржи`.

## Что делает
Строит bar-chart объема по рынку с фильтрами:
- рынок,
- год от/до,
- шаг агрегации (день/неделя/месяц/...).

Проще всего воспринимать этот экран как «погодный прогноз» по активности: где рынок был живой, а где торговля была вялая. Для объемного анализа это важный фон: FootPrint хорошо читается, когда есть ликвидность, а не когда два принта «сделали весь день».

## Как использовать
1. Выберите рынок (например акции ММВБ, FORTS или валютная секция).
2. Задайте диапазон лет `Год от` / `Год до`.
3. Выберите шаг агрегации:
   - `День` дает максимальную детализацию,
   - `Неделя/Месяц` удобны для «макро‑картины»,
   - `Квартал/Год` хорошо показывают режим рынка (низкая/высокая активность).
4. Нажмите `Показать`.

## Практические user-cases
- **Понять контекст перед сделкой**: если по рынку общий объем падает, пробои и импульсы чаще «ложные» и требуют аккуратной тактики.
- **Сравнить режимы**: высокие объемы на новостях/панике vs «летний рынок» с редкими всплесками.
- **Выбрать окно для разборов**: заметили неделю с аномальной активностью -> дальше идти в `Лидеров` и `FootPrint`, чтобы понять, кто именно сделал объем.
