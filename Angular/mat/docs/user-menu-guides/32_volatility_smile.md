# Улыбка волатильности

## Где находится
`Инструменты для трейдеров` -> `Улыбка волатильности`.

## Что делает
Строит IV/Greeks-графики по страйкам:
- выбор актива и экспирации,
- источники данных (БД / MOEX),
- пресеты отображения (`Smile only`, `Greeks core`, и т.д.),
- синхронный crosshair.

## Что вы видите на экране
`Улыбка волатильности` — это набор графиков по одному выбранному активу и экспирации. Главная идея: быстро понять форму IV по страйкам и то, как распределяются греки вокруг ATM.

В управлении есть:
- выбор **ассета**,
- выбор **экспирации**,
- фильтр `Calls / Puts / Calls + Puts`,
- пресеты отображения (от одного графика IV до «ядра» греков),
- выбор оси X: `strike`, `moneyness`, `log moneyness`,
- нормализация (например `per contract` или `money`),
- `Crosshair sync`, чтобы сравнивать точки между несколькими графиками,
- переключатель источника данных `Данные MOEX`.

## Пресеты (как их обычно используют)
Несколько примеров:
- `Smile only`: когда важна только форма IV.
- `Trade core (Smile + Δ + Γ)`: быстрый набор для поиска «где больно» по дельте/гамме.
- `Vol core (Smile + Vega + Theta)`: удобно оценивать риск по волатильности и времени.
- `Price + IV` и `IV today vs prev`: когда хотите увидеть цену/IV и динамику изменения волатильности.

## Практические user-cases
- **Подбор страйков**: найти область, где IV резко меняется, и аккуратнее выбирать ноги стратегии.
- **Оценка skew**: понять, где рынок «боится» (перекос IV по путам/коллам).
- **Сравнение источников**: переключить MOEX/БД и посмотреть, насколько картинка отличается.

## Важно
Опционы чувствительны к источнику данных, ликвидности и времени обновления. Используйте улыбку как аналитический экран и подтверждайте торговые решения другими инструментами (доска опционов, портфельный калькулятор).
