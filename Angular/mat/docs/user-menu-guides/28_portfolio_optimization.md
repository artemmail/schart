# Оптимальный портфель Марковица

## Где находится
`Инструменты для трейдеров` -> `Оптимальный портфель Марковица`.

## Что делает
Рассчитывает оптимизированный портфель по выбранным бумагам, датам, депозиту и риску.
Показывает результат в таблице и pie-chart распределения.

## Как использовать
1. Выберите период и дату вложения.
2. Введите тикеры или загрузите из лидеров.
3. Нажмите `Пересчитать`.

## Параметры, которые реально влияют на результат
- **Бумаги в портфеле**: можно ввести вручную или подтянуть кнопкой `Лидеры по периоду` (быстрый старт).
- **Диапазон дат**: определяет, по какой истории считается статистика.
- **Дата вложений**: точка, относительно которой считается решение «на этот момент».
- **Депозит**: условный размер портфеля (для пересчета долей/сумм).
- **Мин. риск (%)**: ограничение по риску, которое сдвигает решение в более консервативную или более агрессивную сторону.

## Практические user-cases
- **Черновик распределения**: быстро посмотреть, как модель «раскидывает» веса по выбранным тикерам.
- **Сравнение рисков**: один и тот же набор бумаг при разном риске может дать очень разную структуру.
- **Подбор списка на изучение**: модель подсветила неожиданные веса -> проверить эти тикеры в `Лидерах`, `FootPrint` и фундаментальных страницах.

## Важно
Модель Марковица опирается на исторические данные и имеет свои допущения. Это хороший инструмент для «первого приближения», но не заменяет здравый смысл и проверку на ликвидность/риски.
