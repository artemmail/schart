# Таблица сезонной зависимости

## Где находится
`Инструменты для трейдеров` -> `Таблица сезонной зависимости`.

## Что делает
Показывает сезонную матрицу доходностей по месяцам.
При наведении на ячейку отображается мини-график выбранного месяца.

## Как использовать
1. Выберите тикер.
2. Смотрите окраску по месяцам и годам.
3. Наводите на интересные ячейки для контекстного мини-графика.

## Что означает «матрица сезонности»
Это таблица, где по строкам обычно идут годы, по столбцам — месяцы. Цвет клетки показывает, насколько месяц был «плюсовым» или «минусовым». На практике это быстрый способ понять:
- есть ли у бумаги повторяющийся сезонный паттерн,
- насколько он стабилен по годам,
- какие месяцы чаще дают риск/возможность.

## Мини‑график по наведению
Когда вы наводите курсор на месяц, появляется мини‑свечной график за этот период. Это важно, потому что «+5% за март» может быть:
- плавным трендом,
- резким импульсом на новости,
- или «пилой» с большой волатильностью.

## Практические user-cases
- **Планирование сделки по горизонту**: если у бумаги слабые месяцы, можно быть осторожнее с «держать в позицию».
- **Проверка гипотезы**: «в мае часто падает» -> посмотреть несколько лет -> проверить, что именно происходило на графике.
- **Выбор периода для детального разбора**: заметили аномальный месяц -> открыть `FootPrint` и посмотреть структуру объема в ключевые дни.

## Важно
Сезонность — это статистика, а не гарантия. Используйте ее как фон и подтверждайте решения через объем, волатильность и новости.
