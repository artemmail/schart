# Статистика свечного графика

## Где находится
`Инструменты для трейдеров` -> `Статистика свечного графика`.

## Что делает
Строит несколько статистических графиков:
- серии роста/падения,
- внутридневной объем,
- ATR (min/max/avg).

## Что это за статистика и зачем она нужна
Этот экран отвечает на вопросы, которые часто недооценивают:
- «насколько бумага сейчас волатильна»,
- «сколько свечей подряд обычно растет/падает»,
- «как распределяется объем внутри дня».

Это хороший фон для тактики: где ставить стоп, чего ожидать от «продолжения серии» и насколько рынок сейчас «нервный».

## Как использовать
1. Выберите тикер через автокомплит.
2. Настройте диапазон дат (пресет + календарь).
3. Выберите период свечи.
4. Смотрите графики:
   - серии роста/падения помогают оценить характер движения,
   - внутридневной объем показывает, в какие часы обычно активность выше,
   - ATR дает ориентир для «среднего движения» и риск‑параметров.

## Практические user-cases
- **Настройка риск‑менеджмента**: ATR помогает не ставить стоп «внутри шума».
- **Выбор времени торговли**: внутридневной объем показывает, когда инструмент живее.
- **Подтверждение через объем**: увидели необычную серию -> открыть `FootPrint` и проверить, как это было сделано по принту.
