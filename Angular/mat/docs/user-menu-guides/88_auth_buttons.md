# Вход, Регистрация, Выход

Учетная запись в StockChart.ru нужна не «для галочки». Она включает вещи, которые в реальной работе экономят время: избранные пресеты FootPrint, доску избранных, комментарии в блоге, обращения в поддержку, а также доступ к страницам, которые открываются только авторизованным пользователям.

## Где находится
Правый край верхней панели:
- для гостя: `Вход`, `Регистрация`,
- для авторизованного: `Выйти <username>`.

## Что делает
- `Вход`: форма логина с ссылками на восстановление пароля и повторную отправку подтверждения.
- `Регистрация`: создание нового аккаунта.
- `Выйти`: завершение сессии и возврат на главную.

## Что меняется после входа
- становится доступен `MCP Console` и другие разделы с проверкой авторизации,
- можно сохранять настройки графиков в `Избранное` и открывать их в `FavoritesBoard`,
- можно писать в поддержку прямо из интерфейса,
- можно комментировать публикации и ставить лайки.

## Полезная деталь про переходы
Если вы пытаетесь открыть страницу, которая требует авторизацию, сервис перенаправит вас на логин и после успешного входа вернет обратно на исходную страницу (это удобно, когда вы пришли по ссылке на конкретный инструмент).

## Практические user-cases
- «Собрать рабочее пространство»: войти -> настроить `FootPrint` под стиль -> сохранить 5–10 избранных -> открыть их на `Доске FootPrint`.
- «Быстро решить проблему»: войти -> `Написать в поддержку` -> приложить ссылку на график/скриншот и описание.
- «Учиться без хаоса»: читать статьи из `Возможностей` и параллельно сохранять удачные пресеты, чтобы не настраивать всё заново.
