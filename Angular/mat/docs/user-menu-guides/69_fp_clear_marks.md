# FootPrint: Очистить пометки

## Где находится
FootPrint -> `Доп. инструменты` -> `Очистить пометки`.

## Что делает
Удаляет все пользовательские пометки текущего графика и очищает сохраненные уровни для выбранного тикера.

## Когда пользоваться
- график «захламился» старой разметкой и мешает читать текущую ситуацию,
- вы переходите к новому сценарию и хотите начать «с чистого листа»,
- нужно проверить идею без влияния старых уровней.

## Важно
Очистка необратима: если вам нужна разметка «на потом», сначала сделайте скриншот или сохраните ссылку на график.
