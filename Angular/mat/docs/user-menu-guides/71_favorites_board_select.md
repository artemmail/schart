# FavoritesBoard: Настроить избранное

## Где находится
На странице `FavoritesBoard` -> `Доп. инструменты` -> `Настроить избранное`.

## Что делает
Открывает чек-лист, где выбирается, какие избранные графики показывать на доске.

## Как пользоваться
1. Откройте `FavoritesBoard`.
2. Нажмите `Доп. инструменты` -> `Настроить избранное`.
3. Отметьте нужные пресеты и сохраните.

Если отметить «ничего», доска покажет состояние «Ничего не выбрано» (это нормально, просто выберите графики).

## Как обычно организуют наборы
- 6–12 тикеров «на сегодня» (интрадей),
- отдельный набор «среднесрок»,
- отдельный набор под фьючерсы/опционы,
- отдельный набор «разбор» (бумаги из лидеров/всплесков объема).
