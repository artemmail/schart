# Облигации: карта доходности и скринер

## Где находится
`Инструменты для трейдеров` -> `Облигации: карта доходности и скринер`.

## Что делает
Экран облигаций объединяет:
- фильтры (доходность, дюрация, купон, квалификация),
- scatter-карту доходности,
- таблицу выпусков с сортировкой и пагинацией.

## Как использовать
1. Отфильтруйте набор бумаг.
2. Кликните точку на карте для подсветки бумаги.
3. Кликните имя бумаги для карточки выпуска и мини-графика.

## Что есть в фильтрах
Скринер облигаций в StockChart.ru позволяет быстро отсечь «шум»:
- **доходность** (от/до),
- **дюрация** (от/до) и **лет до погашения**,
- **частота купона** (например 1/мес, 1/квартал, 1/полгода),
- отметка **«только для квалов»**,
- режим карты (например «доходность по дюрации» или «доходность к погашению»),
- вкладки по типам MOEX (например ОФЗ и другие группы).

## Карта доходности
Карта помогает увидеть распределение бумаг «одним взглядом». Есть удобные детали:
- можно развернуть карту на весь экран,
- можно выделять область (zoom‑инструмент) и кликом по точке подсветить строку в таблице.

## Таблица выпусков
В таблице обычно смотрят:
- **доходность и цену**, чтобы отсеять явные крайности,
- **объемы** (ликвидность важна не только в акциях),
- **НКД, купон, дату купона, оферту**, чтобы не попасть в неприятный сюрприз по календарю.

## Карточка выпуска
При клике по названию открывается страница выпуска, где собраны:
- рыночные данные (цена/доходность/объем),
- параметры выпуска (ISIN, эмитент, погашение, оферта, валюта),
- мини‑свечной график,
- календарь купонов.

## Практические user-cases
- **Подбор «лестницы»**: отфильтровать по срокам погашения и купону, затем сравнить доходности и ликвидность.
- **Поиск ликвидных выпусков**: сортировка по объему и быстрая проверка «живости» выпуска.
- **Связка с акциями эмитента**: из карточки облигации можно перейти к данным по акции эмитента и посмотреть отчетность/фундаментал (если тикер известен).

## Важно
Облигации могут иметь оферты, ограничения для неквалифицированных инвесторов и нюансы расчета доходности. Скринер помогает отбирать кандидатов, но финальную проверку условий выпуска лучше делать внимательно.
