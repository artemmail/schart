# Опционный портфель (конструктор)

## Где находится
`Инструменты для трейдеров` -> `Опционный портфель (конструктор)`.

## Что делает
Ручная сборка портфеля:
- добавление позиций по SECID,
- подгрузка цепочки опционов,
- расчет PnL и Greeks,
- построение графиков `Now / On expiration / What-if`.

## Как устроен конструктор
Экран разделен на три логичных части:
1. **Выбор контекста**: базовый актив, тип, экспирация и фильтр цепочки (calls/puts/оба).
2. **Позиции портфеля**: таблица, где вы руками задаете `SECID`, тип инструмента, количество, цену, IV (если нужно) и отметку netting для IM.
3. **Цепочка опционов**: список доступных контрактов, откуда удобно добавлять позиции кликом (не перепечатывая SECID).

Есть what‑if параметры:
- `What-if Δσ` (сдвиг волатильности),
- `What-if дата` (сдвиг по времени),
и синхронизация курсора `Crosshair sync` для сравнения серий на графиках.

## Что показывает результат
После `Рассчитать` строятся графики по выбранному пресету:
- PnL (прибыль/убыток),
- греки (Δ, Γ, Vega, Theta, Rho),
в нескольких режимах: `Now`, `On expiration`, `On what-if`.

## Практические user-cases
- **Собрать стратегию**: например, вертикальный спред или стрэддл и сразу увидеть профиль PnL.
- **Оценить риск по веге/тете**: понять, как портфель ведет себя при росте IV или при «сгорании времени».
- **Подготовиться к хеджу**: быстро посмотреть, где портфель становится слишком дельтовым/гаммовым.

## Важно
Это расчетный инструмент. Он помогает понять форму риска и сценарии, но не отменяет проверки ликвидности и реальных котировок в стакане/доске опционов.
