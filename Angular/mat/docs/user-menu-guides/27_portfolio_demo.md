# Торговля на демо-счете

## Где находится
`Инструменты для трейдеров` -> `Торговля на демо-счете`.

## Что делает
Переадресует на обучающий материал (`ServiceNews/Content/Portfolio`) и связан с инструментами демо-торговли внутри FootPrint.

## Как это обычно используют
Демо‑торговля в контексте StockChart.ru — это про обучение и тестирование:
- освоить логику «объем -> сценарий -> вход -> сопровождение» без давления реальных денег,
- потренироваться работать с пресетами и разметкой,
- сравнить несколько подходов на одинаковом наборе тикеров.

Внутри `FootPrint` есть отдельное меню `Демо торги` (виртуальный портфель, сравнение портфелей, быстрые команды купить/продать и т.п.).

## Практические user-cases
- Новичок в объемах: сначала демо‑сделки по простым сценариям (уровень, всплеск объема), потом переход к более сложным.
- Тест новой идеи: сделать 20–30 «виртуальных» проходов и понять, есть ли смысл развивать стратегию.
- Обучение дисциплине: заранее прописать условия входа/выхода и фиксировать результат без самообмана.

## Важно
Это демо‑инструменты и учебные материалы. Они не являются брокерским терминалом и не исполняют реальные сделки.
