# FootPrint: Сделать скриншот

## Где находится
FootPrint -> `Доп. инструменты` -> `Сделать скриншот`.

## Что делает
Сохраняет изображение текущего canvas-графика через сервис загрузки изображений.

## Как это обычно используют
1. Разметьте ключевые уровни/зоны (если нужно).
2. Нажмите `Сделать скриншот`.
3. Получившуюся ссылку вставьте туда, где обсуждаете идею: в блог, в поддержку или в чат.

Скриншоты особенно полезны в объемном анализе, потому что «словами» принт объяснить сложно, а картинка сразу дает контекст.

## Практические user-cases
- Разбор сделки: «вот здесь принт, вот здесь реакция».
- Багрепорт: «вот как отображается график на моем устройстве».
- Обучение: приложить скрин к посту для новичков и показать пример.
