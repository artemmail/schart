# Арбитраж и сравнение доходности (Pair Trading)

## Где находится
`Инструменты для трейдеров` -> `Арбитраж и сравнение доходности`.

## Что делает
Открывает FootPrint в парном (арбитражном) режиме.
Можно строить спред между двумя портфельными формулами или получить пару из сравнения демо-портфелей.

## Как устроен режим арбитража в StockChart.ru
В арбитражном режиме у графика появляется две «ноги»:
- `Портфель 1`
- `Портфель 2`

Сервис строит спред (разницу/соотношение) и позволяет анализировать движение пары как отдельного инструмента: с теми же периодами, датами и привычной логикой чтения свечей/кластеров.

## Типовой сценарий
1. Откройте `Арбитраж и сравнение доходности`.
2. Введите формулы/тикеры для `Портфель 1` и `Портфель 2` (или выберите пару из сравнения портфелей).
3. Выберите период и диапазон дат, нажмите `Показать`.
4. Сохраните удачную конфигурацию в избранное или сформируйте ссылку на текущий график.

## Практические user-cases
- **Relative value**: сравнивать 2 акции из одного сектора, чтобы искать перекосы.
- **Хедж**: условно «акция vs индекс», когда важно убрать рыночный фактор.
- **Проверка идеи**: «сильный/слабый» — кто из пары тянет движение, а кто отстает.
