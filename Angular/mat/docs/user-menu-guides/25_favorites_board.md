# Доска FootPrint

## Где находится
`Инструменты для трейдеров` -> `Доска FootPrint`.

## Что делает
Собирает на одной странице набор избранных графиков из FootPrint.

## Как использовать
1. Сначала добавьте избранные пресеты в обычном FootPrint.
2. Откройте доску.
3. Через `Доп. инструменты` настройте, какие избранные показывать и в какой сетке.

## Зачем это нужно
`FavoritesBoard` превращает «избранное» из списка в рабочий экран. По смыслу это ваша персональная панель мониторинга:
- один экран = несколько графиков,
- один клик = переключение между наборами,
- удобно держать на втором мониторе или на отдельной вкладке.

## Что вы увидите, если «не работает»
На доске предусмотрены понятные пустые состояния:
- если **нет избранного**: сервис попросит сначала добавить пресеты в `FootPrint`,
- если **ничего не выбрано**: откройте `Доп. инструменты` и отметьте нужные графики.

## Практические user-cases
- **Утренний скан**: 6–12 избранных пресетов по «моим» бумагам, чтобы понять, где появился объем.
- **Слежение за уровнями**: держать на доске графики с размеченными зонами, чтобы не искать их заново.
- **Рабочее место под стратегию**: отдельная доска под фьючерсы, отдельная под акции, отдельная под опционы.
