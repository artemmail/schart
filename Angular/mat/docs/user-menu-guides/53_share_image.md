# Опубликовать картинку

## Где находится
`Служебное` -> `Опубликовать картинку`.

## Что делает
Хостинг изображений:
- вставка из буфера/drag-and-drop/файл,
- опциональное сжатие по ширине,
- выбор формата (`webp/jpg/png`),
- выдача публичной ссылки.

После загрузки вы получаете ссылку на файл и превью. Ссылку можно скопировать кнопкой `Copy to Clipboard` и вставить:
- в пост в блоге,
- в сообщение в поддержку,
- в чат/мессенджер коллегам.

## Как пользоваться (коротко)
1. Вставьте картинку `Ctrl+V`, перетащите мышью или выберите файл.
2. При необходимости задайте ширину для ужатия (удобно, когда исходник «тяжелый»).
3. При желании задайте имя (можно оставить пустым, тогда имя будет случайным).
4. Выберите формат: `WEBP` обычно самый компактный, `PNG` без потерь, `JPG` как компромисс.
5. Нажмите `Отправить`.

## Практические user-cases
- Поделиться сделкой: скриншот FootPrint + короткое описание + ссылка в блог/поддержку.
- Приложить доказательство бага: картинка интерфейса + ссылка на воспроизведение.
- Подготовить «чистый» скрин для статьи: ужать по ширине, выбрать формат, вставить в текст.

## Важно про приватность
Ссылка на изображение публичная. Не загружайте документы/скрины с персональными данными, если не готовы делиться ими по ссылке.
