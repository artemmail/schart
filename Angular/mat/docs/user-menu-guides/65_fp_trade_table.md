# FootPrint: Таблица сделок / свечей

## Где находится
FootPrint -> `Доп. инструменты` -> `Таблица сделок`.

## Что делает
Открывает табличное представление текущих данных графика:
- в тиковом/трейдовом режиме — список сделок,
- в свечном — свечные строки.

Дополнительно доступна выгрузка `CSV`.

## Когда это реально нужно
Таблица помогает, когда «глазами по графику» уже не понять, что именно произошло:
- проверить конкретные принты и время,
- отдать данные в Excel/скрипт через `CSV`,
- быстро пробежать глазами по свечам без масштабирования графика.

## Практические user-cases
- «Разобрать свечу»: в тиковом/трейдовом режиме увидеть поток сделок, а не только итоговую дельту.
- «Собрать статистику»: выгрузить CSV и посчитать свои метрики.
- «Проверить данные»: когда есть сомнения, что в визуализации что-то «не так».
