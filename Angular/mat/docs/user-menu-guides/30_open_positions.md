# Открытые позиции

## Где находится
`Инструменты для трейдеров` -> `Открытые позиции`.

## Что делает
График и таблица открытых позиций юр/физ лиц по фьючерсным контрактам.

## Как использовать
1. Выберите контракт.
2. Переключите режим `Позиции / Число лиц`.
3. Включите нужные серии (long/short).
4. Клик по графику синхронизирует дату в таблице.

## Что именно можно смотреть
На странице есть два слоя информации:
- **график по времени** (динамика long/short юрлиц и физлиц),
- **таблица на выбранную дату** (значения по контракту в точке времени).

Можно:
- выбирать контракт из списка,
- переключать «позиции» vs «количество людей»,
- включать/выключать серии (юрики/физики, long/short),
- менять дату кликом по графику или через датапикер.

## Ограничения доступа
Для части контрактов данные могут быть доступны только при активной подписке. В этом случае сервис подсказывает, что можно выбрать бесплатный демонстрационный контракт (например `Si`) или оформить доступ через `Тарифы`.

## Практические user-cases
- **Оценка настроения**: рост long у физиков на пике и рост short у юриков иногда сигнализируют о перегреве.
- **Подтверждение по объему**: увидели смену поведения участников -> открыли базовый актив в `FootPrint` и проверили, как это проявилось в принте.
- **Отбор моментов**: выбрать даты экстремумов по позициям и изучить, что происходило на рынке в эти дни.
