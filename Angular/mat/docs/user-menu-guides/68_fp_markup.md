# FootPrint: Пометки на графике

## Где находится
FootPrint -> `Доп. инструменты` -> `Пометки на графике`.

## Что делает
Открывает редактор разметки:
- выбор инструмента,
- параметры (цвет/толщина/текст/режим),
- удаление выбранной фигуры.

## Для чего это в реальной торговле
Разметка — это «память» вашего сценария. Вместо того чтобы держать всё в голове, вы:
- отмечаете уровни/зоны,
- подписываете идеи прямо на графике,
- готовите скриншоты/обсуждения.

## Практические user-cases
- Уровни и зоны: отметить «где был принт» или «где поглощали».
- План сделки: подписать условия входа/выхода, чтобы не «передумать» на эмоциях.
- Коммуникация: разметить и отправить скриншот с пояснением (в блог/поддержку/коллеге).
