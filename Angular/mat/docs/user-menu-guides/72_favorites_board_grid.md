# FavoritesBoard: Настроить сетку

## Где находится
На странице `FavoritesBoard` -> `Доп. инструменты` -> `Настроить сетку`.

## Что делает
Позволяет задать раскладку колонок/строк для разных размеров набора избранных.

## Зачем это нужно
Когда на доске 4 графика, сетка 2x2 выглядит логично. Когда 9 — удобнее 3x3. Но у всех разные мониторы и привычки, поэтому сетка настраивается.

Настройка задается «по количеству графиков»: для 4 может быть 2x2, для 6 — 3x2, для 12 — 4x3 и т.д. Так доска автоматически подбирает раскладку, когда вы меняете набор избранного.

## Практические user-cases
- Сделать крупные графики: меньше колонок, больше строк.
- Сделать «стену наблюдения»: больше колонок для быстрого обзора большого списка.
- Настроить под ноутбук vs внешний монитор: разные раскладки под разные устройства.
