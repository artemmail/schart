# FootPrint: Volume Search

## Где находится
FootPrint -> `Доп. инструменты` -> `Volume Search`.

## Что делает
Таблица поиска крупных объемов внутри выбранного диапазона:
- время,
- цена,
- max/total volume,
- ask/bid/delta.

## Что означают колонки
Окно показывает отсортируемую таблицу (с пагинацией). Обычно полезнее всего:
- `Max Volume` — максимальный объем в кластере (быстрый «детектор принта»),
- `Total Volume` — суммарный объем кластера (где реально торговали),
- `Ask / Bid / Delta` — направление и баланс агрессии,
- `Trades` и `Bar Size` — дополнительный контекст «сколько было сделок и как это распределено».

## Как использовать
1. Сначала выберите диапазон дат и период в FootPrint.
2. Откройте `Volume Search` и отсортируйте по `Max Volume` или `Total Volume`.
3. Сверяйте найденные уровни с тем, что видно на кластере, и размечайте их пометками.

## Практические user-cases
- Найти «кто напечатал» уровень: большой `Max Volume` часто совпадает с важной реакцией цены.
- Быстро построить карту уровней на день: 5–10 строк Volume Search и вы уже видите «где деньги».
- Проверить идею из сканера: всплеск объема -> открыть диапазон -> увидеть конкретные уровни, а не только итоговую свечу.
