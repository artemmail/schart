# Опционный портфель (из базы)

## Где находится
`Инструменты для трейдеров` -> `Опционный портфель (из базы)`.

## Что делает
Берет позиции из пользовательского портфеля БД и строит те же расчеты PnL/Greeks, что и конструктор.

## Зачем нужен второй экран
Если вы уже ведете портфель в базе (позиции сохранены в аккаунте), не хочется каждый раз набивать SECID руками. Этот экран подтягивает позиции автоматически и рисует те же графики риска.

## Как использовать
1. Выберите базовый актив и тип актива.
2. Выберите портфель (например `Портфель #1` … `#4`).
3. При необходимости задайте what‑if параметры (Δσ и дата).
4. Нажмите расчет и посмотрите профили PnL/греков.

## Практические user-cases
- **Проверить текущий риск**: насколько портфель стал «веговым» после движения рынка.
- **Принять решение по ребалансировке**: где добавить/убрать ноги, чтобы выровнять профиль.
- **Сравнить варианты**: один и тот же портфель при разных what‑if параметрах.
