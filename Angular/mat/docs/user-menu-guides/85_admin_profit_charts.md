# Админка: ProfitCharts

## Где находится
`Админка` -> `ProfitCharts`.

## Что делает
Набор графиков и таблиц по доходам/платежам:
- доход по месяцам и годам,
- накопленный доход,
- сводные таблицы.

## Как обычно используют
Раздел полезен для внутренней аналитики:
- понять динамику выручки по месяцам/годам,
- посмотреть «накопление» и сравнить периоды,
- сверить цифры в таблицах (например общие суммы).

## Важно
Это админская часть. Для обычного пользователя раздел не отображается в меню.
