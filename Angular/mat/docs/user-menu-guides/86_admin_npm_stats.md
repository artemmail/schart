# Админка: Статистика npm

## Где находится
`Админка` -> `Статистика npm`.

## Что делает
График загрузок npm-пакета:
- выбор пакета,
- выбор диапазона (`week/month/year/3years`).

## Как пользоваться
1. Введите имя пакета (например, какой-то внутренний или публичный npm‑пакет проекта).
2. Выберите диапазон: неделя/месяц/год/3 года.
3. Нажмите `Update` — график перестроится.

## Практические админские сценарии
- Понять, растет ли использование пакета.
- Проверить влияние релиза на динамику загрузок.
- Быстро показать статистику в обсуждении/отчете.
