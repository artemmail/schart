# Список фьючерсов

## Где находится
`Инструменты для трейдеров` -> `Список фьючерсов`.

## Что делает
Показывает группированный список базовых кодов фьючерсов.
Из списка можно открыть детальную страницу по тикеру фьючерса.

## Как устроен список
Фьючерсы сгруппированы по базовому активу. Внутри группы обычно видно:
- короткий код (удобен для быстрых ссылок),
- длинный код,
- название базового актива.

Клик по короткому коду открывает страницу детали выбранного инструмента.

## Практические user-cases
- Быстро найти правильный тикер, чтобы открыть его в `FootPrint` или добавить в `MultiCandles`.
- Понять, какой контракт относится к какому базовому активу (полезно новичкам в деривативах).
- Перейти от идеи «по рынку» к конкретному инструменту для анализа объема.
