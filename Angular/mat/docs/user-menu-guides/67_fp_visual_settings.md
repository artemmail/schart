# FootPrint: Визуальные настройки

## Где находится
FootPrint -> `Доп. инструменты` -> `Визуальные настройки`.

## Что делает
Открывает менеджер настроек рендера:
- блоки и панели,
- тема/поведение,
- кластера и свечи,
- индикаторы,
- пресеты.

Подробности по режимам кластеров см. в статье `20_footprint.md`.

## Что обычно настраивают в первую очередь
- режим отображения колонок (`Classic`, `MarketDelta`, `Volume+Delta`, `Volume`, `Density`),
- цветовую схему и контраст под ваш монитор/освещение,
- толщину/размеры элементов, чтобы цифры читались без увеличения,
- какие панели включены (например, свечи + кластера, дополнительные слои).

На вкладке «Блоки» настройка «Объем в цвет свечи» отображает объем единым столбиком
в цвет растущей или падающей свечи, без разделения на покупки и продажи. Она действует
как для объема внутри графика, так и для отдельного нижнего блока. Если открытие равно
закрытию, цвет определяется преобладающим направлением сделок по объему; для одиночной
сделки — ее направлением. По умолчанию настройка выключена.

## Практические user-cases
- «Скальпинг»: сделать минималистичный пресет без лишних слоев, чтобы быстрее видеть принт.
- «Разбор уровней»: пресет с акцентом на объем и плотность.
- «Работа вечером»: темная тема + спокойная палитра (см. переключение темы).
