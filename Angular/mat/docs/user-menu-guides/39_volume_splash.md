# Необычные всплески объемов

## Где находится
`Инструменты для трейдеров` -> `Необычные всплески объемов`.

## Что делает
Сканер аномального объема:
- период среднего,
- глубина сканирования,
- минимальный коэффициент всплеска.

## Как работает «всплеск»
Идея простая: сравнить текущие максимальные объемы с «обычной нормой» по инструменту.
Вы задаете:
- **Считать среднее по** (окно для базовой средней активности, например 1–12 месяцев),
- **Глубина сканирования** (на каком промежутке искать всплеск, например 1–4 недели),
- **Минимальный всплеск** (например `3`, то есть «в 3 раза выше среднего»).

Результат — таблица, где можно быстро открыть бумагу в `FootPrint` и посмотреть, чем вызван объем.

## Практические user-cases
- **Поиск «движения на событии»**: новости/отчеты часто проявляются именно всплеском объема.
- **Скан «где началось»**: понять, какие бумаги ожили раньше рынка.
- **Переход в глубину**: открыть тикер в `FootPrint`, затем `Top Orders` и `Volume Search`, чтобы увидеть структуру принта.
