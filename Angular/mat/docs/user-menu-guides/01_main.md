# Главная

Главная страница StockChart.ru устроена как «приборная панель»: она не пытается заменить рабочие инструменты, а быстро показывает срез рынка и дает короткие переходы туда, где вы уже принимаете решения по объему, структуре сделки или фундаменталу.

## Где находится
Кнопка `Главная` в верхней панели, URL: `/`.

## Что показывает
На стартовой странице собраны блоки‑виджеты со сводкой:
- быстрые ссылки на ключевые инструменты,
- тепловая карта рынка (`MarketMap`),
- лидеры рынка (`Leaders`),
- мини‑мультиграфики,
- фрактальный барометр,
- лента блогов/обновлений.

В реальной работе это удобная точка входа: вы открываете сайт, «снимаете температуру» и уже дальше переходите в нужный раздел, не перелистывая меню.

## Как использовать (типовой утренний сценарий)
1. Выберите рынок в селекторе (акции/деривативы и т.д.).
2. Просмотрите `Лидеры` и/или `Всплески объемов`, чтобы быстро найти активные бумаги.
3. Откройте конкретный тикер в `FootPrint` и разберите, чем сделано движение: агрессией, поглощением, «пустотой» ликвидности или новостью.
4. При необходимости сравните сектор целиком через `MarketMap` -> `MultiCandles`.

## Практические user-cases
- Поиск «бумаги дня»: лидеры по объему -> FootPrint -> разметка уровней -> сохранение в избранное.
- Быстрый обзор рынка без эмоций: MarketMap показывает, где «горит», а где рынок спокойный.
- Переход от сканера к проверке идеи: Leaders/Barometer дают список кандидатов, FootPrint показывает структуру принта, фундаментал — «кто это вообще».

## Подсказка
Если при переходе на инструмент система просит авторизоваться, значит выбранная страница доступна только после входа (например `MarketMap`, `MultiCandles`, `FavoritesBoard`).
