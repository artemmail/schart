# Админка: Статистика пользователей

## Где находится
`Админка` -> `Статистика пользователей`.

## Что делает
Показывает агрегированную статистику платежей по пользователям и раскрываемую детализацию по платежам.

## Что показывает таблица
Обычно в таблице видно:
- пользователь и email,
- сколько всего оплачено,
- количество платежей,
- максимум/минимум,
- последний заход,
- дату истечения подписки.

Строки раскрываются (expand) и показывают историю платежей конкретного пользователя (дата/сумма).

## Практические админские сценарии
- Проверить, почему у пользователя «пропал доступ»: посмотреть последнюю оплату и дату истечения.
- Найти «сломанную» запись: пользователь оплатил, но платеж не дошел до таблицы — сверить по деталям.
- Поддержка: быстро ответить на вопрос «до какого числа действует подписка».
