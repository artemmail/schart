# FootPrint: URL на текущий график

## Где находится
FootPrint -> `Доп. инструменты` -> `URL на текущий график`.

## Что делает
Формирует ссылку на текущее состояние (тикер/период/диапазон/режим) и открывает ее в новой вкладке.

## Что входит в ссылку
Ссылка включает ключевые параметры анализа, чтобы человек по ней увидел **тот же самый график**:
- тикер (или `Портфель 1 / Портфель 2` в арбитраже),
- период,
- шаг цены (в кластерном режиме),
- диапазон дат,
- режим (`candles / clusters / arbitrage`).

Пример (упрощенно):
```text
/FootPrint?ticker=SBER&period=15&rperiod=day&startDate=...&endDate=...&mode=clusters
```

## Практические user-cases
- Отправить ссылку коллеге: «посмотри вот этот принт на уровне».
- Приложить к обращению в поддержку: так проще воспроизвести проблему.
- Сохранить как закладку: «готовый набор» под конкретный сценарий/тикер.
