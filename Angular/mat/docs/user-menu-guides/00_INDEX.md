# Руководство по пунктам меню StockChart.ru

StockChart.ru — сервис инструментов для трейдеров, где акцент сделан на анализе объемов (кластера/FootPrint), быстрых рыночных сканерах, опционном и фьючерсном блоке, фундаментальных данных, а также на ИИ‑ассистенте в `MCP Console`.

Эта папка — навигация по пользовательскому меню фронтенда `Angular/mat`. В каждой статье вы найдете:
- где находится пункт меню и какой у него URL,
- что именно он показывает,
- как его обычно используют на практике (user-cases и связки с другими инструментами).

Если вы хотите одним взглядом увидеть все разделы и сразу перейти к нужному: откройте [Карту разделов StockChart.ru](05_sections_map.md).

## Быстрый старт (если вы впервые)
1. Начните с базы по кластерам: [Кластерный график для начинающих](10_capability_cluster_beginner.md).
2. Откройте основной рабочий экран для объемного анализа: [Кластерный график (FootPrint)](20_footprint.md).
3. Для поиска идей используйте сканеры и обзорные экраны: [Лидеры рынка](37_leaders.md), [Необычные всплески объемов](39_volume_splash.md), [Тепловая карта рынка](22_market_map.md).
4. Для быстрых запросов и «сделай мне отчет» попробуйте [MCP Console](03_mcp_console.md).

## Доступ и ограничения
- Часть страниц открывается только после входа (например `MarketMap`, `MultiCandles`, `FavoritesBoard`, `MCP Console`). Если вы гость, вас перенаправит на форму входа.
- Для некоторых функций может требоваться активная подписка (например отправка запросов в `MCP Console`). Управление подпиской: [Тарифы](02_tariffs.md).
